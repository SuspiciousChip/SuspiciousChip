# Setup (5 minutes)

1. On GitHub create a **public** repo named exactly `YOUR_USERNAME` (same as your username). Tick "Add a README".
2. Upload everything in this folder to it (keep the `.github/` folder, it's hidden on some systems).
3. In `README.md`, replace `YOUR_USERNAME`, `YOUR_LINKEDIN`, `YOUR_HANDLE`, and the text. In `config.json`, set your name, tagline and self-rated skills (0-10).
4. Repo → Settings → Actions → General → Workflow permissions → **Read and write permissions**. Save.
5. Repo → Actions → run `update-profile`, then `snake` (Run workflow). After both finish, refresh your profile.

Recolor everything: edit `scripts/theme.py` (and the colors in `snake.yml`, plus `722f37` in the README badge URLs).
